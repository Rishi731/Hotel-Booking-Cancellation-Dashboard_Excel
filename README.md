# Hotel-Booking-Cancellation-Dashboard_Excel
Developed an Excel dashboard analyzing 117K+ records of hotel reservations to track cancellations by year, hotel type, guest type, country, and monthly patterns for better booking insights.

Highlights
- Shows total reservations and total cancellations across three years.
- Breaks down cancellations by hotel type (City Hotel and Resort Hotel).
- Tracks month-wise cancellation trends.
- Compares total vs cancelled bookings by country.
- Analyzes cancellations based on customer type (Couples, Family, Single).
- Includes slicers for quick year filtering.
- Data cleaned, transformed, and summarized using PivotTables.
